
# Chart.js Bubble Chart

A bubble chart with custom colors, borders and hover styles, built with Chart.js 2.7.2 and Bootstrap 4.1.3 in plain HTML and JavaScript.

## Getting started

Open `index.html` in your browser. No build step or installation is needed, Chart.js and Bootstrap are loaded from a CDN.
